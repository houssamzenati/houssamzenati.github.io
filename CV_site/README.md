# Academic CV

`main.tex` is the website CV source; `main.pdf` is the compiled public-download file. The application copy uses the same content in `CV/imperial-cv.tex` in the job-search folder.

Build from this directory with `pdflatex main.tex` or `tectonic main.tex`. The CV contains four pages and includes funding, teaching, supervision, service and publications. Regenerate the PDF after changing the source.
